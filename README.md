## 几个高频问题

**轻量应用服务器可以按月买吗？**

可以，包年和包月都在支持范围内，页面上有按月售卖的套餐款；按小时的按量计费则没有，这是ECS才有的能力。

**流量超了怎么收费？**

内地活动套餐标注200M峰值不限流量；海外版套餐含月流量包，超出按地域计费，比如中国香港0.153美元/GB。

**能装宝塔面板吗？**

预装镜像里就包含宝塔Linux面板（阿里云专享版）和宝塔Windows面板，另有1Panel、WordPress、Docker、LNMP等，创建实例时选一下就行。

**内地节点和香港节点怎么选？**

内地节点（杭州、北京等）建站需要备案，带宽规格最高200M峰值；香港节点免备案，峰值带宽30M。备案和带宽，按业务实际需求二选一。
